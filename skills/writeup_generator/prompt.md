# Write-up Generator Skill

You are generating a CTF challenge write-up.

## Format

Produce a polished Markdown document with:

1. **Title** – challenge name and category.
2. **Description** – what was provided.
3. **Analysis** – how the challenge was identified.
4. **Solution** – step-by-step walkthrough with commands and output.
5. **Flag** – the final flag.
6. **Exploit Code** – if applicable, a proof-of-concept script.

## Guidelines

- Use fenced code blocks for commands and output.
- Be concise but thorough.
- Explain *why* each step was taken, not just *what* was done.
